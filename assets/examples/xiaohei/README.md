使用规则：

- 只参考角色比例、线条密度、留白、颜色克制度和“小黑承担核心动作”的方式。
- 不要照抄样图里的具体构图、物件、标注或隐喻。
- 每张新图仍应从当前文章重新发明一个低科技物理隐喻。
