# 可视化研究所插画方法论提炼

来源：可視化研究所《CORPORATE PROFILE / 「絵本」案内 ver.》，2026-05 PDF。

这份资料的核心不是“画得可爱”，而是把复杂、抽象、陌生的信息，经过语言整理、信息密度控制、角色化叙事和长期品牌规则，转成让目标读者愿意靠近、看得懂、记得住、可持续复用的视觉资产。

## 一句话方法

先把文字变成可被理解的结构，再把结构变成有吸引力、有温度、低负担、可复用的视觉语言。

## 核心流程

```text
原始文本 / 想表达的价值
→ 关键词抽取
→ 要约 / 再语言化
→ 目标受众理解
→ 信息密度控制
→ 隐喻与角色化
→ 版式整理
→ 插画 / 图解 / 品牌资产
→ 长期运营可复用的数据交付
```

## 3 个关键原则

### 1. 从语言开始，而不是从画面开始

只要“想传达的内容已经成文”，就可以从文字进入视觉制作：

- 抽取关键词。
- 要约核心判断。
- 按目标读者重写表达。
- 让文章关系、段落关系和信息层级先清楚。
- 再进入布局、图解和插画。

对 cc2image 的启发：生成提示词前必须先生成 `message_core`、`target_reader`、`keyword_extract`、`compressed_sentence`、`visual_translation`，避免直接把原文塞进画面。

### 2. 目标受众决定信息密度与变形程度

资料强调“简化不等于一定能传达”。插画需要根据受众、品牌和媒介调节：

- 年轻 / 轻松：更高的亲和感、爱着、共感、普通符号。
- 专业 / 熟练：更低变形、更高信息准确度。
- 品牌 / 长期：保持识别性、统一性和可扩展性。
- 公共传播：注意颜色可访问性、误解风险和文化风险。

对 cc2image 的启发：风格选择不应只按主题词，还要按 `audience_level`、`deformation_level`、`information_density` 和 `trust_requirement` 控制画面。

### 3. 为长期品牌运营交付，而不是只生成单张图

资料把插画、图解和设计视为长期品牌系统：

- 交付应考虑二次利用、商用利用、后续编辑。
- 能做成系列、角色、图标、版式规则、VI guideline。
- 插画不只是装饰，而是企业、产品、服务的解释层和记忆层。

对 cc2image 的启发：批量生图时增加 `series_consistency`、`reuse_notes`、`editable_layers_hint`、`brand_rules`，让输出更像一套内容资产。

## “絵本形式”的拆解

这份资料提出的“绘本形式”可以拆成两组元素：

### A. 惹きつける要素：让人愿意靠近

- 插画：降低心理距离，减少复杂感。
- 短文案：把核心判断压成可记忆句子。
- 语气 / 画风：形成亲近感与品牌温度。
- 台词：让抽象信息有人的声音。
- 主人公：把读者、产品或问题角色化。
- 故事：把静态概念变成可跟随的变化过程。

### B. 自分ごと化要素：让人觉得“和我有关”

- 读者处境：画出用户现在遇到的问题。
- 选择 / 分流：让读者看到自己位于哪条路径。
- 前后变化：展示从困惑到理解、从混乱到行动。
- 记忆钩子：用角色、物件或隐喻绑定核心观点。

## 可复用的视觉类型

### 1. Infographic｜信息图解

适合统计数据、调查结果、复杂指标。目标是“复杂数据和流程也能被任何人读懂”。

提示词应明确：数据对象、比较关系、重点指标、阅读顺序、最低文字量。

### 2. Storyboard｜故事板

适合流程、服务说明、教程、案例。目标是“把顺序整理成故事”。

提示词应明确：起点、步骤、转折、终点、角色动作。

### 3. Mapping｜俯瞰图 / 关系图

适合系统全貌、组织关系、服务结构。目标是“一眼看见关系”。

提示词应明确：中心节点、层级、连接关系、空间隐喻。

### 4. Main Visual｜主视觉

适合品牌、产品发布、系列内容。目标是“一张图定方向”。

提示词应明确：品牌印象、关键词、主物件、留白、视觉记忆点。

### 5. Cut Illust｜切片插画 / 图版

适合文章正文、FAQ、功能说明。目标是“强调一个关键点”。

提示词应明确：单一观点、单个动作、少量标注、不要塞满。

### 6. Guide Character｜引导角色

适合复杂服务、定期内容、教程和产品引导。目标是“给系统加一个可信、亲近的案内役”。

提示词应明确：角色身份、表情、动作、职责、重复出现规则。

### 7. Pictogram / Icon｜图标符号

适合入口、导航、公共说明。目标是“用人人能懂的符号传递消息”。

提示词应明确：符号含义、轮廓规则、颜色规则、禁用歧义。

### 8. VI Guideline｜视觉规则

适合品牌长期运营。目标是“统一感和复用性”。

提示词应明确：色板、线条、字体、角色、版式、禁用项。

## 质量检查清单

每张图生成前检查：

1. 是否先完成关键词抽取和要约？
2. 目标读者是谁？他们已有多少背景知识？
3. 信息密度是否与读者匹配？
4. 画面是否有“愿意靠近”的元素？
5. 是否有一个主人公、物件或隐喻作为记忆钩子？
6. 这张图只表达一个核心判断吗？
7. 是否避免了误解、冒犯、颜色不可读和无意义装饰？
8. 如果是系列图，角色、色彩、线条和版式是否可复用？
